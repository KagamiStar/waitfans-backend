## 一、项目现状概览

当前后端基于 SpringBoot 2.7 + MyBatis-Plus + Spring Security + JWT + Netty + ElasticSearch + Redis 构建，已实现视频平台核心链路（用户认证 → 视频上传/播放 → 弹幕/评论/搜索 → 私信IM），代码质量较高，模块结构清晰。

## 二、需完善的已有功能

### 2.1 评论嵌套回复 ⚠️ 高优先级

**现状**：评论支持 `rootId`、`parentId` 字段，数据库已设计好楼中楼结构，Controller 有 `/comment/reply/get-more` 端点。但当前前端只展示一级评论。

**需完善**：

| 需求 | 说明 |
|------|------|
| 评论回复 API | 已有 `/comment/add`（带 root_id/parent_id），需确认递归查询子回复的效率，建议限制嵌套深度为2层（B站模式） |
| 更多回复分页 | `/comment/reply/get-more` 需确保分页逻辑正确，返回子回复总数 |
| 通知触发 | 回复评论时需触发 `msg_unread.reply` 和 `msg_unread.at` 增量 |

---

### 2.2 视频分享功能 ⚠️ 中优先级

**现状**：无分享相关 API。数据库 `video_stats` 表有 `share` 字段但无实际业务逻辑。

**需完善**：

| 需求 | 说明 |
|------|------|
| 分享统计 API | `POST /video/share` — 记录分享行为，更新 `video_stats.share` |
| 分享链接生成 | 可选：生成短链接或分享码，供站外传播 |
| 分享来源追踪 | 可选：记录分享渠道（微信/QQ/微博等），用于数据分析 |

---

### 2.3 视频编辑/删除 ⚠️ 高优先级

**现状**：投稿后无编辑/删除能力。稿件管理仅查看。

**需完善**：

| 需求 | 说明 |
|------|------|
| 视频编辑 API | `POST /video/edit` — 修改标题、标签、描述、分区、封面（不可改视频文件） |
| 视频删除 API | `POST /video/delete` — 软删除（status 改为已删除状态），已有 `VideoController.changeStatus` 可复用但需加权限校验 |
| 编辑权限 | 仅投稿者本人或管理员可编辑/删除 |
| OSS 清理 | 删除视频后，调度异步任务清理 OSS/MinIO 中的视频文件和封面文件 |

---

### 2.4 关注/粉丝系统 ⚠️ 高优先级

**现状**：完全未实现。数据库无关注相关表。

**需新增**：

| 需求 | 表/API | 说明 |

## 五、优先级建议

### 🔴 高优先级（P0 — 核心体验闭环）

1. **关注/粉丝系统** — B站核心社交关系链
2. **消息通知内容列表** — 当前只有计数，无实际内容
3. **视频编辑/删除** — 创作者基本需求
4. **举报/申诉系统** — 内容安全与创作者权益保障

### 🟡 中优先级（P1 — 功能完善）

5. **首页分区推荐** — 内容发现效率提升
6. **搜索筛选增强** — 搜索体验对标B站
7. **弹幕功能增强** — 用户体验细化
8. **视频分享** — 传播渠道建设
9. **播放历史管理** — 基础体验完善
10. **收藏夹编辑/删除** — 收藏管理闭环
11. **操作日志/审计** — 管理安全基础

### 🟢 低优先级（P2 — 远期规划）

12. **动态系统** — 社区生态建设
13. **视频合集** — 内容组织升级
14. **用户等级/经验** — 用户激励体系
15. **专栏系统** — 内容形态扩展
16. **直播系统** — 高难度基础设施
17. **推荐算法优化** — 需要数据积累
18. **全局配置管理** — 运维效率
